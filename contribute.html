Ground rules

Licences

Most code is BSD-3-Clause, as LG released it. Some LG files carry other terms in their headers; keep those as they are. New files use BSD-3-Clause. Never copy code from GPL projects. Reading them for ideas is fine.

Privacy

Never commit or paste personal data: TV IP addresses, serial numbers, MAC addresses, account names, tokens or keys. Check logs before attaching them.

Testing

Say exactly what ran on which TV and release. "Not tested on a TV" is a fine answer. Untested shim behaviour stays opt-in.

Conduct

Be respectful and constructive. Everyone taking part follows the Code of Conduct. Report security problems privately, as described in the security policy.
