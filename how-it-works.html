How it works

LG's engine and embedder are prebuilt for webOS 26 and aren't rebuilt here. Instead, the packager wraps them in what an older TV is missing.

The pipeline

--legacy runs tools/make-compat-ipk.sh after the normal build.

1. Normal build

flutter-webos build webos produces LG's webOS 26 bundle: engine, embedder, plugins and your app.

→

2. Repackage

Bundle glibc 2.41 and the C++ runtime, patch the ELF loader and library paths, add the shims.

→

3. Legacy IPK

A normal webOS package. At run time the shims convert webOS 26 calls to what the TV provides.

What gets fixed

Each row is something that stopped the app on webOS 6, with the fix applied.

Problem on older webOSFix
LG's binaries need glibc 2.38; the NDK's glibc needs kernel 5.15 or newerBundle Debian armel glibc 2.41 (built for kernel 3.2 or newer) in lib/compat/
LG's binaries need a newer libstdc++Bundle the NDK's own C++ runtime (GCC 13, ARMv7)
webOS only grants Luna permissions to the real main executableNo wrapper script: point the binary's ELF interpreter at the bundled loader
The devmode jailer's LD_LIBRARY_PATH overrides RUNPATHUse DT_RPATH, and add bundled libraries as direct dependencies so they load first
Firmware preloads an old libSegFault.so into every processBundled loader patched to skip /etc/ld.so.preload
wl_proxy_marshal_flags missing (Wayland older than 1.20)Wayland shim implements it on the 1.11 API
Shell protocol v2 requested, compositor offers v1Shim records the advertised versions and clamps binds
The remote's Back key never reaches the app, or arrives as EscapeShim enables Back on the shell surface and sends a route pop
Firmware ships only libwayland-egl.so.0 or only .so.1A small forwarder library loads whichever exists
Old media API takes its video window from SDL, even for audioA stand-in libSDL2 hands it Flutter's window, or a placeholder for audio
DRM licence URL in the load request is ignored on old releasesTranslated into the older DRM client flow (PlayReady)
The Mali driver blocks about 10 ms per frame waiting for a bufferOpt-in second EGL surface on the same window, alternated every frame

The parts

📦

Packager

tools/make-compat-ipk.sh: bundling, ELF patching with patchelf, shim injection, IPK output.

🧩

Wayland shim

compat/wayland-shim: missing Wayland functions, version clamping, Back key, EGL timing, dual surface, video placement frames.

🎬

Media shim

compat/ndl-sdl-shim: webOS 26 media calls mapped to the old media and DRM APIs, plus a single-player fallback for webOS 5.

🔐

Widevine proxy

compat/widevine: opt-in. Uses the TV's CDM, serves a clear manifest on localhost and decrypts segments in place.

🔗

EGL forwarder

compat/wayland-egl-forward: one library name that works across firmware versions.

📊

Firmware checker

tools/fw-compat-check.py: finds missing libraries and functions per release from firmware symbol data.

The full technical write-up is in legacy-webos/README.md.
