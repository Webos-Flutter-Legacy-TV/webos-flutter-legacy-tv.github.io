Turn on Impeller

Add this key to webos/meta/flutter-conf.json, next to the keys already there (full file):

"engine-switches": { "enable-impeller": true }

Recommended, including for apps that use video_player with the plugins fork.

Dual surface (opt-in)

An empty webos/meta/compat-dual-surface file alternates two EGL surfaces, so rendering no longer waits about 10 ms per frame for the Mali driver. Raster time drops from about 17 ms to 7 ms.

It switches itself off while video or audio is loaded, or while an external texture (such as a webos_image_texture image) is registered: with Impeller those don't draw on the second surface.

Known limits on webOS 6

Media

DASH streams with VP9/Opus tracks don't load through the media pipeline (Widevine ones play through the hardware route). Only one video plane shows at a time. Playback resumes 4–7 s after a seek.

Widevine

Opt-in, experimental, DASH only: the hardware route (L1) plays up to 4K. The earlier software route was removed because it decrypted media in the app. See DRM progress.

Package size

The legacy package is about 15 MB larger, because it bundles glibc, the C++ runtime and the shims.

Store submission

No legacy package has been submitted to LG's Content Store yet, so whether LG accepts it is unknown.
