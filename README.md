# webos-flutter-legacy-tv.github.io

Source of https://webos-flutter-legacy-tv.github.io, the website of the
[Webos-Flutter-Legacy-TV](https://github.com/Webos-Flutter-Legacy-TV) organisation.

Plain HTML, CSS and a little JavaScript, with no build step. Push to `main`
and GitHub Pages publishes it.

| File | Page |
| --- | --- |
| `index.html` | Home |
| `compatibility.html` | webOS releases, what works on webOS 6, performance, limits |
| `get-started.html` | Building an existing app for older TVs |
| `development.html` | Contributor setup, step by step |
| `how-it-works.html` | The packager and shims |
| `contribute.html` | Ways to help, open work, ground rules |
| `assets/site.css`, `assets/site.js` | Shared styles; header, footer and nav, copy buttons |

The header and footer are generated by `assets/site.js`, so add a new page to
the `pages` list there. Keep the facts in step with
[legacy-webos/README.md](https://github.com/Webos-Flutter-Legacy-TV/flutter-webos/blob/main/legacy-webos/README.md).
