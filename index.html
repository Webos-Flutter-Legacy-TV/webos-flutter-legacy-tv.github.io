Flutter apps on older LG webOS TVs

LG's Flutter SDK builds apps for webOS 26 only. Add --legacy to the same build and the app also runs on older TV releases, with no changes to LG's engine and no changes to your Dart code.

What you get

Your webOS 26 build gets the runtime and compatibility layers it needs, so it runs on older TVs.

⚙

Same app, same build

No fork of your app. One build command produces both the webOS 26 package and the legacy package.

▶

Video, audio and DRM

video_player, audioplayers, PlayReady, plus an opt-in Widevine route that uses the TV's own CDM.

⌨

Remote control

D-pad, OK and Back behave like they do on webOS 26: Back pops the current route.

⚡

Fast rendering

Impeller is supported, and tuned frame pacing works around the old Mali driver's buffer waits.

🔎

Check before you try

A firmware checker shows which libraries and functions an app needs that a webOS release is missing.

🧪

Test apps included

Six test apps cover UI, input, plugins, video, DRM and audio, and write results you can compare.

Where it runs

webOS 6 has been tested on a real TV. Other releases were checked against firmware symbol data.
