Flutter apps on older LG webOS TVs

LG's Flutter SDK for webOS builds apps for webOS 26 only. This project repackages the same build so it runs on older TV releases, without rebuilding LG's engine. Verified on webOS 6; the firmware check also passes for webOS 22–25.

Status by webOS release

webOS 6 has been tested on a real TV. Other releases were checked against firmware symbol data: every system library and function the engine, embedder and plugins need was looked up. Kernel, Wayland and GPU driver behaviour still need real TVs.

webOSStatusNotes
26LG's targetUse LG's SDK as is.
22–25Expected to workNothing missing in the firmware check; not yet run on a TV.
6VerifiedTested on webOS 6.5.3 (OLED C1, 2021). Results below.
5Likely worksOne media function missing; shimmed with a single-player fallback.
4Needs workNeeds bundled libsystemd and libcurl, plus one more media shim.
1–3Not startedOlder system APIs throughout; much more work.

Get started

You need a Linux x86_64 machine with curl, xz, dpkg-deb, python3, npm and cmake, and a TV in Developer Mode.

  1. Get the tools

    git clone https://github.com/Webos-Flutter-Legacy-TV/flutter-webos.git
cd flutter-webos/legacy-webos
WEBOS_NDK_ACCEPT_EULA=1 ./setup.sh   # toolchains and runtime, into git-ignored folders
. ./env.sh                           # puts flutter-webos, ares and patchelf on PATH

    Nothing is installed system-wide. Only set WEBOS_NDK_ACCEPT_EULA=1 if you accept the LG webOS NDK licence.

  2. Build with --legacy

    cd my_app
flutter-webos build webos --release --legacy
#   build/webos/arm/release/...ipk                          webOS 26
#   build/webos-compat/release/<app-id>_<version>_arm.ipk   older webOS

  3. Install and run

    ares-install build/webos-compat/release/*.ipk
ares-launch <app-id>

    For plugins, use the plugins fork. The porting guide covers configuration, plugin notes and testing.

Performance

LG's build uses Skia unless the app turns on Impeller. On webOS 6, Impeller is much faster for animated UI. Turn it on in webos/meta/flutter-conf.json:

{ "engine-switches": { "enable-impeller": true } }
Scene at 1080p (frames per second)SkiaImpellerImpeller + dual surface
Four large animated tiles with opacity and shadows175254
Constant-speed list scroll586161
64 animated tiles121924

Dual surface (compat-dual-surface) is opt-in: with Impeller, a change drawn just before the screen goes still can stay invisible. The cause hasn't been found yet.

How it works

make-compat-ipk.sh takes the ordinary webOS 26 bundle and fixes what stops it from running on an older TV. LG's engine and embedder binaries are not rebuilt.

Bundled runtime

A newer glibc and C++ runtime ship inside the app. The loader and library paths are patched, so the TV's old libraries are never picked up.

Wayland shim

Fills in functions that Wayland 1.11 lacks, matches protocol versions to the compositor, and delivers the remote's Back key as a route pop.

Media shim

Converts webOS 26 media calls to the older media API: video window, audio-only players, and the PlayReady licence flow.

Opt-in Widevine

A local proxy that decrypts DASH segments with the TV's own CDM, for apps that turn it on. Software security level only.

Frame pacing

Optional second EGL surface so rendering doesn't wait for the Mali driver to release a buffer.

Firmware check

fw-compat-check.py checks an app's libraries against each webOS release's firmware symbols before you try it on a TV.
